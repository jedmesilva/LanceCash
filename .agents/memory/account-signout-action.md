name: Account sign-out action
description: Visual placement and clarity for signing out in Lance Cash.
---

The sign-out control in Lance Cash's account modal should be grouped with the other account actions, not presented as a disconnected text link or standalone button. Use a clearly labeled action row with a sign-out icon and concise supporting text.

**Why:** The user said the isolated control looked out of place and did not read as a logout action; adding only an icon and color was not enough.

**How to apply:** When changing the account modal, keep sign-out in the same visual action group as the other account options, distinct from navigation but integrated into the modal.
